# Sonyx1978

Личен сайт на български с адаптивен дизайн. Използва HTML, CSS и JavaScript, без външни библиотеки, шрифтове или стъпка за компилиране.

## Локално стартиране

Необходим е Python 3. От директорията на хранилището изпълнете:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Отворете `http://localhost:8000` в собствения си браузър. Спрете сървъра с `Ctrl+C`.

## Редактиране

- `index.html` — текстове, секции и връзки. Личният текст е начален шаблон и може да се персонализира.
- `styles.css` — цветове, типография и оформление за телефон и компютър.
- `script.js` — мобилна навигация с поддръжка на клавиатура.
- `favicon.svg` — икона на сайта.

Връзките към GitHub сочат към `sonyx1978`. Не са необходими API ключове или други тайни.

## Публикуване с GitHub Pages

1. Запишете файловете с комит и ги качете в клон `main` на `sonyx1978/sonyx1978`.
2. В GitHub отворете **Settings → Pages**.
3. За **Source** изберете **Deploy from a branch**, след това **main** и **/ (root)**, и запазете.
4. Изчакайте успешното публикуване. GitHub показва адреса на сайта в същата секция.

Хранилището `sonyx1978/sonyx1978` е проектно хранилище. Очакваният адрес с настройките по подразбиране е `https://sonyx1978.github.io/sonyx1978/`. За адрес `https://sonyx1978.github.io/` е необходимо отделно хранилище с име `sonyx1978.github.io`.

Създаването на файловете локално не ги качва в GitHub и не публикува сайта. Относителните пътища към ресурсите поддържат и двата вида адреси.
